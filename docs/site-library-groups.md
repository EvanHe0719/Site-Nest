# 我的站点：分组与布局

分组是用途分类，与个人／工作等空间独立。默认不替用户分类；旧站点全部保留在未分组中。左侧提供全部站点、未分组及自定义分组计数；右侧可切换紧凑卡片和列表。原有搜索与空间筛选继续生效，搜索也匹配分组名称。

新建／重命名通过表单完成（1–40 字符，禁止重复名称）。在卡片下拉框选择目标分组即可移动。删除分组需确认，只移除归类，站点、网址、空间、浏览身份及登录数据不变。分组标题可折叠，搜索时临时展开匹配结果。排序、删除站点等操作位于卡片“更多”菜单。

数据位置为 uiSettings.siteLibrary，包含 groups、assignments、collapsed、view。独立主进程 sites:organize 接口校验操作与站点／分组编号，既有数据迁移补空默认值，不增加 schemaVersion。该字段接入设置的完整快照及 applicationSetting 增量同步；需开启设置同步，未承诺本轮已完成真实 Google Drive 端到端验证。

验证：355 项单元测试通过；实际 Electron 中测试新建、移动、分组筛选、改名、删除保留站点、列表切换和重启保存，1480px 与 1060px 均通过；1480px 截图已核对。lint、typecheck、动作审计通过。本轮未重打包。
