# 内容标签 v1

栖页 schema 15 引入统一的本地内容标签目录。它与浏览器“页签”和“页签组”完全独立，只关联以下对象：

- 本地日程
- 习惯目标
- 时间轴记录
- 站点
- 用户脚本

## 数据模型

第一版只有一层 `ContentTagGroup`，不支持嵌套树。`ContentTag` 使用 `canonicalName` 和仅做首尾空格、连续空格、大小写折叠的 `normalizedName`。`ContentTagAlias` 必须由用户明确创建；系统不会根据中文同义词、拼音或描述自动推断。

对象通过 `tagIds` 引用内容标签。日程（内部模型仍使用兼容字段 `localTasks`）和时间轴原有的文本 `tags` 字段继续保留，迁移不会删除旧值，也不会把旧文本自动合并为新内容标签。

## 合并与撤销

合并前只读预览会返回来源、目标、各自引用数，以及日程、习惯、时间轴、站点、用户脚本五类受影响计数。用户确认后：

1. 所有来源引用原子迁移到目标标签。
2. 来源标签软删除。
3. 来源名称成为目标标签的明确别名。
4. 关联对象本身不会被删除。
5. 最近一次合并可使用反向快照无损撤销；如果合并后的引用又被修改，撤销会拒绝覆盖新数据。

反向快照只保存在主进程数据中，不通过 `state:get` 或内容标签快照暴露给渲染进程。

## IPC 边界

渲染进程只能调用 `content-tags:*` 窄 IPC：读取目录、保存/删除分组、标签与别名、预览/执行/撤销合并，以及按对象类型和 ID 更新 `tagIds`。所有写入先完整保存候选状态，成功后才替换内存状态。

## 迁移

schema 14 可直接迁移到 schema 15。缺少新集合时初始化为空，不生成演示标签。旧对象上未知的 `tagIds` 会原样保留以避免静默数据丢失；所有新的标签写入只允许引用当前活动目录中的 ID。
