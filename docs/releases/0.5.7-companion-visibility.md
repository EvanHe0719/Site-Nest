# 栖页 0.5.7：小序网页内悬浮实现

## 最终交互

- 旧版 Shell 侧栏、独立轨道和布局避让已删除。小序只以圆形状态球悬浮在当前网页右下角，不占用网站宽度，也不另开窗口或 Chromium 进程。
- 点击右下角状态球会打开单一玻璃会话面板；天气、健康提醒与问答都在同一对话流中完成，不再使用三个页签。
- 顶部小序图标使用与右下角一致的可爱胶囊眼造型，但 0.5.7 仍是不可操作的后续功能占位。
- 默认状态球明亮、睁眼并带多层通透涟漪；视频全屏或持续专注达到阈值时才闭眼打盹并降低亮度，点击和回答时使用更明显的生命感光圈。
- 对话气泡不再重复头像或名称；问候是可随滚动离开的普通首条消息，底部不显示冗余的 Provider 与提醒状态文案。

## 输入与隐私边界

- 网页组件运行在独立 world、closed Shadow DOM 和同进程隔离输入层中；点击、键盘输入和提交会被截断，不会穿透到网页搜索框或误点网页内容。
- 小序只通过受控 IPC 获取运行状态、刷新天气和发送用户手动输入的问题，不读取网页正文、表单、Cookie 或 Token，也不把 DeepSeek Key 注入网页。
- “启用基础小序”不会自动开启天气、护眼、喝水或活动提醒；DeepSeek API Key 仍使用本机 `safeStorage`。

## 天气与状态

- 已配置且有数据时直接显示当天温度和天气状况，不再显示“天气已开启”。
- 未配置、正在获取、暂不可用分别显示真实状态；用户在问答框输入文字不会改变天气状态。
- 首次启用且没有缓存时会立即请求天气；全屏、屏幕共享、系统离开和用户主动隐藏等静默规则继续有效。
- schemaVersion 保持 18，不修改站点、书签、Cookie、BrowserProfile 或 Partition。

## 验证

正式 `栖页-0.5.7-便携版.exe` 已用隔离数据启动验证：标题栏显示 `0.5.7` 而非 DEV，网页右下角状态球可打开会话面板，旧侧栏与独立轨道不存在。
