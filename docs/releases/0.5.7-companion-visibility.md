# 栖页 0.5.7：小序可发现性修复

## 问题确认

此前生成的 `栖页-0.5.6-便携版.exe` 早于小序六阶段代码提交；本机现有数据仍为 schema 17，也没有 `uiSettings.companion`。因此该 EXE 中看不到小序不是设置操作错误。

即使直接运行小序开发代码，旧用户默认关闭时 Rail 也会整体隐藏，导致无法从主界面发现设置入口。

## 0.5.7 修复

- 顶部始终显示全局小序圆点入口；聚合主页点击后直接进入小序设置，网页中点击后展开同一个小序面板。
- 浏览网页时始终显示右侧小序 Rail；未启用时使用低饱和状态明确标识。
- 未启用时仍允许打开面板查看说明和进入小序设置。
- “启用基础小序”只开启基础伴随状态；天气、护眼、喝水、活动提醒保持关闭，网页 AI 仍需用户主动调用。
- 全屏、屏幕共享、系统离开和用户主动隐藏等硬静默条件继续隐藏 Rail。
- schemaVersion 保持 18，不修改站点、书签、Cookie、BrowserProfile 或 Partition。

## 验证目标

生成 `栖页-0.5.7-便携版.exe` 后，启动首页顶部即可看到小序圆点入口；打开任意内置网页后，还会看到浏览区域最右侧的“小序”Rail。点击后即使尚未启用，也会出现说明面板。
