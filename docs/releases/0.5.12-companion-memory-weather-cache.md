# 栖页 0.5.12：小序本机记忆与天气缓存

## 结果

- “本机对话记忆”默认关闭。用户开启后，小序只保留最近 12 轮已提交问题与成功回答，并在后续问答和新页面中恢复上下文。
- 设置页显示已保存轮数并提供“清除记忆”。关闭记忆不会继续记录；清除后已有网页中的记忆气泡同步移除。
- 天气快照写入既有本机 `companionRuntimeState`。应用重启时恢复快照；未过期不重复请求，已过期则显示旧快照并后台刷新。
- 修改天气城市会清除旧缓存，避免把上一城市的温度误当作当前城市。

## 隐私边界

- 对话记忆不读取网页正文、尚未提交的输入、表单、Cookie、Token 或 API Key。
- 每条内容最多 3,000 字符，总量最多 24 条消息。
- `syncableCompanionSettings` 不包含记忆开关，Google Drive 安全快照不包含 `companionRuntimeState`，因此对话和天气缓存都只留在当前电脑。
- DeepSeek 与天气请求仍只由主进程发起。

## 天气接口判断

本次反复显示“正在获取天气”的已确认原因是旧实现只有进程内缓存，应用重启后缓存为空。付费天气接口可提供独立容量与服务目标，但不能代替客户端缓存；因此本版本先修复本机缓存，不在缺少用户订阅和 API Key 时假设或写入付费配置。

## 验证

- 333 项单元测试全部通过，包含 WeatherCache 持久化、恢复、过期、城市切换、最近对话长度、角色、字段清洗、DeepSeek 消息顺序与 Google Drive 隔离。
- 小序设置、网页悬浮卡片记忆恢复和界面动作诊断 3 项真实 Electron 回归通过。
- UI 动作审计覆盖 89 个动作与 42 个关键控件，错误和警告均为 0。
- 完整 Electron 套件 41 项中 39 项通过；系统画中画探针超时、NodeSeek 截图引擎 `UnknownVizError` 两项失败，输出显示 NodeSeek 的 403→403→200 业务流程已完成，失败不在本次记忆或天气路径。
