# 栖页 0.5.17：我的站点分组与布局

日期：2026-09-05。此版交付此前尚未打包的站点分组功能。

## 使用

完全退出旧版（包括系统托盘中的栖页），运行 `release/栖页-0.5.17-便携版.exe`，确认左上角版本为 0.5.17。

打开“我的站点”，在左侧新建分组，在站点卡片的分组下拉框中移动站点。支持分组重命名、折叠、筛选、删除及卡片／列表布局切换。删除分组保留站点；旧站点默认保持未分组。

## 已导入 Bitwarden 的使用

进入“自动化中心 → 浏览器扩展”，选择安装时使用的浏览身份并确认扩展已启用。目标网页必须使用同一身份：普通网页、NodeSeek 和 SAP 分别隔离。打开或刷新该身份的网页，点击地址栏右侧的 Bitwarden 图标，在扩展弹窗中登录并解锁。

栖页导入的是扩展代码副本，不会复制 Chrome 中已登录的密码库。Bitwarden 后台消息和部分 Chrome API 仍存在兼容问题，真实登录、输入框提示、自动填充尚未通过验收；弹窗空白或无法填充不能仅靠重新导入解决。此版未修改 Bitwarden 兼容层。

保留旧版便携 EXE。验证使用隔离测试数据目录。
