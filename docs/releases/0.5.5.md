# 栖页 0.5.5

## 目标

在不改变现有 Electron `WebContentsView` 会话与持久浏览身份的前提下，让用户无需先添加站点就能搜索/打开任意网页，并将设置从单一长页改为分类管理。

## 通用搜索

- 统一解析完整 HTTP/HTTPS URL、无协议域名、localhost、私网 IP 与普通关键词。
- 完整 URL 直接打开；普通域名默认 HTTPS，localhost/私网 IPv4 默认 HTTP；路径、查询和片段保留。
- 脚本、data 和未批准的本地协议直接阻止；其它自定义协议进入现有外部应用确认流程，不会在网页视图内执行。
- 空状态使用当前空位打开一个临时页签；已有正常网页时，全局搜索默认新建当前空间页签并继承当前 BrowserProfile/Partition。
- 临时网页不写入站点库、固定列表或 Chrome 书签。

## 全局面板

- `Ctrl/Cmd + K` 与顶部搜索按钮打开 Command Palette。
- 支持当前会话、我的站点、Chrome 书签、本地任务、互联网搜索和直接 URL。
- 支持上下选择、Enter、Esc、鼠标、防抖与焦点恢复。本地结果计算不读磁盘，输入改变不发起网络请求。

## 搜索引擎与历史

- 内置 Google、Bing、百度、DuckDuckGo，模板集中在 Registry 中，查询正确 URL 编码。
- 默认引擎持久化；全局面板的临时选择不改写默认值。
- 历史默认保存最多 100 条、相同查询合并并记录使用次数；支持单条删除、全部清除和停止记录。
- Token、OAuth Code、Session、密码等 URL 参数会被删除；带 URL 用户名/密码或明显敏感赋值的记录直接丢弃。

## 设置中心

- 实际分类为常规、搜索与新标签页、浏览与性能、翻译、计划与通知、连接与集成、账号与同步、数据与备份和关于；没有创建无内容的占位分类。
- 只挂载当前分类的设置卡片；右侧内容独立滚动，窄窗口显示顶部分类选择器。
- 卡片支持紧凑收起/展开；Zoho 详细表单由 `<template>` 惰性创建，保留已有公开配置和主进程安全凭据。
- 设置搜索使用显式 Registry，旧 Chrome 书签、Zoho、翻译、通知、内存和弹窗入口继续定位到新分类。未保存表单离开当前分类前会确认。

## 数据边界

- schema v10 新增 `uiSettings.search` 和 `searchHistory`。迁移可重复执行，不重复搜索引擎，不迁移或清理 Cookie/Partition。
- Google、Zoho 密钥仍在 `safeStorage`；搜索不增加任何 Token IPC。
- 清除搜索历史只修改 `searchHistory`，不影响站点、书签、会话、计划或浏览历史。
