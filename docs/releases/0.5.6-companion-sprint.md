# 栖页 0.5.6 小序伴随助手 Sprint

## 1. 最终状态

PARTIAL。核心单实例 Rail、六状态、健康提醒、手动城市天气、显式 DeepSeek 辅助、持久化、同步边界和完整自动化回归已实现。仍缺少可验证的屏幕共享全程检测、应用内通知中心，以及任务要求的每场景 5 分钟性能采样，因此不能报告 COMPLETE。

## 2. 最新仓库审计结果

Electron 44、原生 HTML/CSS/JavaScript、BrowserWindow Shell + 每页签 WebContentsView、contextIsolation/sandbox、窄 IPC、JSON 兼容镜像 + SQLite 记录级同步、Electron safeStorage。现有浏览身份为 `persist:qiye-sites` 与 `persist:qiye-sap-support`。

## 3. WebContentsView z-order 审计

WebContentsView 属于原生 ContentView 层，Shell DOM 的 CSS z-index 不能稳定盖在其上。小序没有采用覆盖网页的悬浮 DOM。

## 4. 最终采用的 Companion UI 宿主方案

采用 Shell Renderer 内的 44px `CompanionEdgeRail`。展开时复用浏览区域的 CSS Grid 右侧列并缩小 WebContentsView Bounds；与页面动作面板互斥。

## 5. 是否新增 Renderer 或 BrowserWindow

没有。Companion 使用现有 Shell Renderer；未创建 Companion BrowserWindow、透明窗口、第二套 Chromium 或常驻远程页。

## 6. 小序六状态实现

`idle`、`focusedDocked`、`resting`、`bubbleTip`、`expanded`、`silentHidden` 集中在 `CompanionStateMachine`，未知事件被拒绝。

## 7. ActivitySessionTracker 实现

由 `CompanionRuntimeService` 统一每 15 秒调度，读取前台、最小化、系统 Idle、锁屏、睡眠和后台自动化布尔状态。Renderer 只以 5 秒节流上报“发生了有意义操作”，不上传按键内容、鼠标坐标或轨迹。

## 8. 专注贴边和休眠规则

有效前台活动持续 20–60 秒后进入 focusedDocked；系统 Idle、后台或最小化不累计；气泡 12 秒后回到低干扰状态。

## 9. 健康提醒规则

本地引擎支持护眼、喝水和活动三个独立间隔。它们是一般休息提示，不提供医疗诊断。

## 10. Cooldown、Snooze 和勿扰机制

每类提醒记录最近显示、确认和延后时间；支持延后、今日不再提醒、暂停/恢复及跨午夜安静时间。“已喝水”只更新提醒冷却，不创建 HabitCheckIn 或坚持星。

## 11. Weather Provider

主进程 `OpenMeteoWeatherProvider` 使用 Open-Meteo Geocoding 与 Forecast API；Renderer 不直接联网。当前正式 UI 只支持用户手动填写城市。

## 12. 天气缓存和轮询

默认 30 分钟内存缓存，可配置 10–180 分钟；单一 in-flight 请求、15 秒超时、最多两次有限退避，睡眠时停止并取消请求。

## 13. 天气提醒与去重

本地规则判断未来两小时降雨、强风、高低温和相邻快照温差；同类城市事件 6 小时去重。判断不依赖 DeepSeek。

## 14. DeepSeek Provider 复用

复用现有 `TranslationProviderRegistry`、`OpenAICompatibleTranslationProvider` 和 `TranslationService`，未增加第二份 AI Provider。

## 15. API Key 安全边界

继续使用 `translation:openai-compatible:default` safeStorage secret reference。Renderer 无 Token/API Key getter，密钥不进状态、日志或同步。

## 16. AI 本地降级机制

DeepSeek 未配置或失败时，状态机、健康提醒、天气快照和本地天气规则仍可使用；界面显示中文错误。

## 17. 当前网页总结

只有用户显式点击才提取标题、有限标题层级和最多 15,000 字可见正文；跳过表单、editable、隐藏元素、代码和栖页注入 UI。

## 18. 选中文字解释

复用已有 SelectionActionService 与页内 Popover，不新建页签；选区文本不进入 Shell Renderer。

## 19. 敏感网站确认

Zoho、SAP、邮箱和内部站点首次总结显示主进程确认；登录、OAuth、SSO、支付和密码页永久阻止。始终允许的 hostname 仅保存在本机运行态。

## 20. 通知中心集成

已接入现有 Windows `DesktopNotificationService`，提供打开、确认/已喝水、延后 10 分钟和今天不再提醒。仓库当前没有应用内通知中心，因此未实现应用内通知列表。

## 21. UIActionRegistry 集成

新增 16 个 companion 动作，严格审计为 89/89 已注册、可执行、可测试，0 错误。

## 22. 快捷键集成

“AI 与关怀”分类包含展开小序、显式总结当前网页；默认不占用组合键，由用户自行绑定。

## 23. Google Drive 同步范围

同步启用状态、专注/Idle 阈值、安静时间、健康规则和天气开关/轮询间隔；不上传城市、经纬度、天气缓存、提醒运行态、AI 批准站点、网页正文或对话。

## 24. 设置中心调整

“计划与通知”新增小序、手动城市天气、三类健康提醒和安静时间设置，并进入设置搜索。

## 25. 数据迁移

schema 17→18，新增 `uiSettings.companion` 和 `companionRuntimeState`；旧用户默认关闭。迁移可重复，不修改站点、书签、计划、时间轴、习惯、坚持星、OAuth、Cookie、BrowserProfile 或 Partition。
