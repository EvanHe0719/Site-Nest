# 栖页 0.5.0 Phase 5：页面资源识别与网页视图内存治理

## 修改文件与能力

- `electron/browser/page-resource-service.cjs`：按用户操作扫描当前页的 `a[download]`、常见直链文件、图片、视频、音频和 `source`；资源只在内存中短期保存，下载继续经过 Electron 原生下载流程和保存位置确认。
- `electron/browser/webview-lifecycle-manager.cjs`：建立 `active / warm / suspended / restoring / crashed` 生命周期和省内存、标准、高性能三档池策略；休眠会销毁 WebContents，但保留 URL、会话元数据和浏览身份分区。
- `electron/browser/download-manager.cjs`：按 WebContents 跟踪活动下载，使内存治理不会休眠正在下载的页面。
- `electron/main.cjs`、`preload.cjs`：增加窄 IPC，用于资源扫描、限时网络资源检测、资源下载、生命周期状态、保持运行和手动休眠；Token、Cookie、请求头和响应正文不进入渲染进程。
- `renderer/`：页面动作侧栏增加资源清单和显式网络检测；“设置与数据”增加网页视图内存模式、休眠时间、运行数量和保存操作；当前会话显示休眠/保持运行状态。
- `test/unit/resource-lifecycle.test.cjs`、`test/integration/resource-lifecycle-electron.test.cjs`：覆盖资源白名单、加密播放列表拒绝、网络监听注销、池策略、受保护页签、WebContents 销毁、Cookie/分区保持、UserScript 与资源缓存清理和恢复原 URL。

## 资源识别安全边界

- 普通扫描只读取当前 DOM 中可直接访问的资源 URL、类型、建议文件名、MIME、大小和来源元素；不读取 Cookie、Authorization、密码、表单值或响应正文。
- 高级网络检测必须由用户点击开启，只监听当前 WebContents，最长 60 秒，仅保留 URL、MIME 和 Content-Length；停止、导航或关闭页面时注销监听器。
- `.m3u8`、`.mpd` 和 `.key` 被明确拒绝；不提取 HLS Key、鉴权 Token、DRM 数据，不绕过登录、订阅、付费墙、验证码或网站权限。
- 资源 ID 必须来自当前页面本次扫描缓存，渲染层不能伪造任意 URL 触发下载。

## 内存策略与恢复

- 省内存：1 个活动视图、0 个预热视图。
- 标准（默认）：1 个活动视图、最多 1 个预热视图，默认后台 15 分钟后可休眠。
- 高性能：1 个活动视图、最多 3 个预热视图，默认后台 15 分钟后可休眠。
- 播放媒体、活动下载、待上传文件、受控登录弹窗、`beforeunload`、未发送 Zoho 回复草稿、独立窗口和用户标记“保持运行”的页面不会自动休眠；无法可靠判断时采取保守保护。
- 休眠清理翻译控制器、选区动作、用户脚本运行时和资源缓存；不清理 Cookie、LocalStorage、IndexedDB、Cache 或 `persist:qiye-sites`。重新选择页签时以原浏览分区恢复最近 URL。

## 内存对比

真实 Electron 探针在同一次运行中创建 6 个 WebContents，切换省内存模式后保留 1 个并休眠 5 个：

- 活动 WebContents：`6 → 1`。
- `app.getAppMetrics()` 私有内存合计：`500700 → 360604`，单次下降约 28%。该指标会受 Chromium、GPU 和 Windows 内存回收时机影响，不作为固定承诺。
- 休眠前后目标站点 Cookie：`1 → 1`。
- 恢复后的浏览分区：仍为 `persist:qiye-sites`。
- 休眠后的用户脚本 Runtime 和页面资源缓存均已清理。

## 数据迁移

- schema 仍为 v8；`uiSettings.browserMemory` 缺失时补齐为 `standard / 15 分钟`，页签缺失 `keepRunning` 时补齐为 `false`。

## 已知限制

- DOM 扫描不能发现只存在于应用内部状态、Service Worker 或加密播放器协议中的资源；这是安全边界，不会通过注入任意远程 JavaScript绕过。
- 网络检测使用 Electron session 的单个 `onResponseStarted` 监听槽；当前项目没有其他同类监听器，未来若新增需要统一复用调度器。
- 休眠后恢复的是最近 URL、登录身份和网站持久存储，不恢复已销毁 WebContents 的内存 DOM、滚动位置、历史栈或未提交普通表单；这些页面应由“保持运行”保护。
- Chromium 私有内存下降受操作系统回收时机影响；验收以 WebContents 数量、运行时清理和会话保持为确定性指标。
