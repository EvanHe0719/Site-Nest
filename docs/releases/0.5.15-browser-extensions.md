# 栖页 0.5.15：Chrome 扩展便携验证版

发布日期：2026-09-05。包含当前源码中的扩展管理、NodeSeek 人工签到入口和此前日程、记忆等修改，数据结构版本仍为 19。

## 使用

关闭旧版后运行 `release/栖页-0.5.15-便携版.exe`。进入“自动化中心 → 浏览器扩展”，选择浏览身份，导入包含 `manifest.json` 的解压扩展目录。NodeSeek 页面应选择 NodeSeek 身份。

目前不是 Chrome Web Store 在线安装。Bitwarden 后台仍有兼容问题，不能将“已加载”视为自动填充已通过。

- 直接运行 win-unpacked 中的打包程序：测试扩展加载、内容脚本、工具栏和弹窗集成测试通过。
- 便携 EXE 在隔离数据目录启动并正常退出，截图确认 0.5.15 版本与浏览器扩展页面。
