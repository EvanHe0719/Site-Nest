# 栖页 0.5.9：自动化中心概览优化

日期：2026-09-03

## 完成内容

- 签到任务首页改为参考图中的轻量页签、三张独立统计卡和紧凑任务卡布局。
- 原“沙箱状态”卡不再展示，第三张卡改为“今日执行记录”，统计真实执行日志中的成功、未完成和处理中次数。
- 今日完成率根据当前启用状态与实际签到结果显示；没有启用任务时显示“—”，不会用 100% 制造已执行的错觉。
- 奶昔论坛的执行时间、自动开关和最近运行信息集中到独立信息条；图标尺寸被明确约束，不再撑大卡片。
- 未适配签到的 NodeSeek 与 LINUX DO 继续保留真实状态，不计入“已纳管签到入口”，并可直接打开对应页面。

## 数据与安全边界

- 统计只读取本机已有的奶昔签到状态、站点助手日志和网页脚本日志，不新增后台扫描，不读取网页 Cookie 或正文。
- 未发现固定签到入口的网站不会被算作已纳管，也不会通过猜测接口执行账号操作。
- schemaVersion 继续使用 18，本次没有数据迁移或清理动作。

## 验证结果

- 326 个单元测试与 39 个 Electron 集成测试全部通过。
- 界面动作审计覆盖 89 个注册动作、42 个关键控件，错误与警告均为 0。
- 在 1200×850 和最小 1060×700 窗口中完成截图检查：三张统计卡保持对齐，任务操作与运行信息不重叠，页面无巨大盾牌图标。
- `win-unpacked` 正式应用使用隔离数据启动并生成自动化页截图，随后正常退出。
