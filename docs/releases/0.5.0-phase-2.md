# 栖页 0.5.0 Phase 2：划词与整页翻译

## 修改文件与能力

- `electron/translation/`：新增 Provider Registry、OpenAI-compatible Provider、翻译批处理/去重/重试/取消、选择动作、页面文本提取、双语渲染、动态观察器和站点规则。
- `electron/main.cjs`：翻译请求只在主进程执行；敏感站点确认、网页内部动作、原生翻译菜单、自动翻译规则和页面生命周期清理接入既有 `WebContentsView`。
- `electron/preload.cjs`：只暴露状态、配置、连接测试和打开翻译菜单；不存在读取 API Key、网页正文或翻译缓存的 IPC。
- `renderer/`：设置页新增 Provider 安全配置，工具栏翻译按钮改为真实原生菜单；未配置时明确显示不可用。
- `test/unit/translation-core.test.cjs`、`test/integration/translation-electron.test.cjs`：覆盖公开配置归一化、HTTPS、JSON 对齐、安全密钥边界、选择内存清理、双语/仅译文/动态 DOM 和恢复原文。

## 数据迁移与安全

- schema 从 v5 升级到 v6，新增 `uiSettings.translation`。
- 普通状态只保存 API Base URL、模型、源/目标语言、默认显示模式、选词按钮开关和站点规则。
- API Key 使用现有 `connector-secrets.json` 的 Electron `safeStorage` 加密信封，引用为主进程内部固定项；渲染进程只能看到 `hasApiKey` 布尔值。
- 迁移可重复执行，不修改 `persist:qiye-sites`，不清理网页 Cookie、Cache、Google/Zoho 登录、会话、站点或书签。
- 翻译缓存只在内存；选择关闭或导航时清理选择原文/译文，页面关闭、导航或恢复原文时中止请求并断开观察器。

## 翻译行为

- 只有用户点击右键翻译或选区旁按钮时才读取选中文字；不轮询 Selection API，不读取密码框。
- 整页提取只处理可见文本节点，跳过脚本、样式、代码、表单控件、可编辑区、隐藏内容、纯数字、URL 和文件名。
- 请求按字符数分批、相同文本去重、单并发执行，瞬时网络/超时/限流/API 错误最多重试一次；段落 JSON 不对齐时拆分重试。
- 双语模式在原文后插入独立 span；仅译文模式临时隐藏原文本节点；恢复时按内存映射恢复，未替换节点 `innerHTML` 或链接地址。
- 动态 DOM 只有翻译开启时注册 `MutationObserver`，节流后仅提取未翻译的新节点；恢复、导航和关闭时释放。
- 同源 iframe 会参与提取；跨域 iframe 不绕过同源限制，并在完成提示中标记“部分框架未翻译”。

## 已知限制

- 仓库没有真实翻译 API Key，因此本阶段验证了 Provider 协议、请求结构和模拟响应解析，没有宣称任何外部翻译账号已连接成功。
- 当前正式 Provider 为 OpenAI-compatible；Google Cloud、Microsoft Translator 与 DeepL 只保留 Registry 扩展点，未使用非官方免费接口。
- “在翻译网站中打开”由用户显式点击后把当前选中文字交给系统浏览器中的 Google Translate；不会后台自动打开。
- 跨域 iframe 受浏览器同源策略限制，无法提取或注入；界面会如实提示部分框架未翻译。
- 页面休眠时的观察器暂停与后台标签内存定量治理属于 Phase 5；当前已在恢复、导航、渲染进程退出和页面关闭时清理。
