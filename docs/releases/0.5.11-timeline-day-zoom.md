# 栖页 0.5.11：时间轴按日缩放与记录悬浮详情

日期：2026-09-04

## 完成内容

- 工作线和个人线的波形节点、事件簇卡片与列表行，点击后先打开就近悬浮详情卡；卡片展示记录事实，右上角提供修改、删除和关闭。
- 波形工具栏增加“月 / 日”两级刻度。月刻度显示全年 12 个月；日刻度显示当前所选月份的每一个实际日期。
- 月份导航在日刻度下继续保留，便于直接切换月份，不必先退回全年。
- 图表内向上滚轮会按照指针所在横坐标选中月份并进入日刻度；向下滚轮返回月刻度。达到两级边界后不拦截页面正常滚动。
- 鼠标以外仍可使用可见按钮、月份按钮、Enter 和空格操作；悬浮详情可通过背景、关闭按钮或 Escape 关闭。

## 数据边界

- 继续使用 schema v18；不新增记录字段，不迁移或删除现有工作/个人时间轴数据。
- 月/日选择继续复用每条轨道已有的 `scope` 与 `selectedMonth` 本机视图设置，不影响导出的原始事件日期。

## 验证结果

- 330 个单元测试全部通过。
- 41 个真实 Electron 集成测试全部通过；时间轴探针覆盖个人记录悬浮详情、8 月 31 个逐日坐标、滚轮月→日→月切换和状态持久化。
- 界面动作审计覆盖 89 个动作、42 个关键控件，错误和警告均为 0。
- 源码运行与正式便携版均使用隔离数据完成 1400×900 可见截图检查；详情卡位于窗口内，修改/删除/关闭按钮可见，逐日坐标完整。
