# 栖页 0.5.0 最终交付报告

发布日期：2026-08-30

## 1. 最终状态

**PARTIAL**

0.5.0 的本地实现、迁移、自动化测试、Windows x64 便携版构建和成品启动验证已经完成。没有真实 SAP Support、Zoho Desk 或外部翻译 Provider 凭据，因此这些外部账号端到端链路不能诚实标记为已验证；正式界面保持未配置状态，没有填充假结果。

## 2. 当前技术栈审计

- Electron 44、`BrowserWindow` 与多 `WebContentsView`，前端为原生 HTML/CSS/JavaScript。
- 主进程维护原子 JSON 状态，当前 schema v8；网页身份使用 `persist:qiye-sites` 持久分区。
- Cookie、LocalStorage、IndexedDB、Cache 与网页登录态由 Chromium 分区保存；敏感连接器和翻译密钥使用 Electron `safeStorage` 加密信封。
- 渲染层保持 `contextIsolation`，仅通过 preload 暴露窄 IPC；网页和用户脚本不能访问 Node 或任意 Electron IPC。

## 3. 参考项目和许可证审计

审计见 `docs/research/desktop-workbench-reference.md`。本轮仅参考 Noi、Ferdium、Super Productivity、Violentmonkey、旧版 Immersive Translate 与 Traduzir páginas web 的产品边界或公开概念，没有复制其文件、函数或样式，也没有把浏览器扩展直接嵌入栖页。Noi 当前许可证无法确认，按不得复制处理；其他仓库的 Apache-2.0、MIT 或 MPL-2.0 状态只作为审计记录，本发行物没有新增这些项目的源代码声明。

## 4. 浏览器基础完成情况

- 原生右键菜单覆盖文本、链接、图片、可编辑区和地址栏，并对密码框、下载与外部协议执行白名单限制。
- `window.open`、`target=_blank`、POST、OAuth/SSO 重定向、`postMessage`、关闭和弹窗下载进入受控弹窗；支持转为普通页签。
- 弹窗跳转审计只在内存保存最近 50 条，URL 移除用户名、密码、query 和 fragment，单窗口最多保留 20 个去重 Origin/Path。
- 站点策略支持受控弹窗、普通页签、保留 opener 与显式 POST 许可；危险协议不交给内置浏览器。

## 5. 登录弹窗和 SAP Support Notes 测试结果

真实 Electron 本机夹具已验证普通弹窗、受控弹窗、POST、两次 OAuth 重定向、共享 Cookie/Partition、`window.opener.postMessage`、`window.close`、弹窗下载与转普通页签。SAP Support 与 Universal ID 的真实账号、页面结构和线上跳转链未验证；没有据此宣称 SAP 登录成功。

## 6. 划词翻译完成情况

- 支持原生右键“翻译选中文字”和选区旁按钮；只在用户点击时读取选区。
- 密码框、空文本和超限文本不翻译；关闭、导航或页面销毁会清除内存中的原文、译文与请求。
- 支持重新翻译和显式在翻译网站中打开，未配置 Provider 时明确不可用。

## 7. 整页翻译完成情况

- 支持双语、仅译文、恢复原文、动态 DOM 增量翻译和同源 iframe。
- 仅处理可见文本节点，跳过脚本、样式、代码、表单控件、可编辑区、隐藏内容、URL、文件名和纯数字。
- 翻译启用时才建立节流 `MutationObserver`；恢复、导航、休眠和关闭时中止请求并释放映射。
- 跨域 iframe 不绕过同源策略，界面提示“部分框架未翻译”。

## 8. 翻译 Provider 和隐私说明

- 正式实现 OpenAI-compatible Provider；Google Cloud、Microsoft Translator 和 DeepL 仅保留 Registry 扩展点。
- API Key 只进入主进程 `safeStorage`，不保存到 localStorage、普通状态、日志或渲染状态。
- 请求按字符数分批、去重、单并发、可取消；瞬时错误有限重试，结果数量不匹配时拆分重试。
- 敏感工作网站首次翻译需要原生确认；缓存只在内存，不使用非官方免费接口，不伪造结果。本轮没有真实 Provider 密钥，外部翻译服务未做线上验证。

## 9. 本周、本月任务完成情况

- 新增本地周、月、全部和已完成视图，以及空间首页“本周计划”。
- 任务支持空间、状态、优先级、开始/截止时间、备注、标签和多条提前提醒。
- 时间以 UTC 保存并记录创建时设备时区；任务与提醒仅存本机，不上传 Google 或外部日历。

## 10. 桌面提醒、托盘和开机启动说明

- 单计时器调度最近提醒，新增、编辑、完成、删除、启动和系统恢复时幂等重排。
- 支持本地通知、打开任务、完成和延后 5/10/30 分钟；动作按钮是否可见取决于 Windows 通知能力。
- 托盘提供打开栖页、今天任务、添加任务、暂停提醒和退出；关闭到托盘、开机启动和启动最小化均默认关闭，只有用户启用后生效。
- 完全退出应用后不会继续提醒，没有安装 Windows 服务或计划任务。

## 11. 用户脚本兼容范围

- 支持 `@match`、`@include`、`@exclude`、`@run-at`、受控 `@grant`、`@connect` 及第一批白名单 GM 能力。
- 不支持 `unsafeWindow`、`@require`、`@resource`、Node、Shell、文件系统、任意 IPC 和全局跨域通配。
- 第三方脚本普通登录页需要逐脚本、逐域名的原生高级风险确认；OAuth/SAML 回调、支付、密码管理和系统页始终硬阻止。
- 远程更新默认关闭，变化只生成 Hash 与差异审查，确认前不替换本地副本。

## 12. 内置脚本完成情况

- 提供默认停用的“恢复复制与选择”内置脚本与当前页临时动作。
- 仅恢复普通正文的选择、复制、右键和 `user-select`，不读取输入框、不联网、不绕过登录、订阅、付费墙、验证码或网站鉴权。
- 内置脚本在敏感页面始终阻止；执行记录只保存脚本、域名、结果、耗时与脱敏错误。

## 13. 资源识别安全边界

- 用户主动扫描当前 DOM 的下载链接、常见文件、图片、视频和音频；高级网络检测最长 60 秒，只监听当前 WebContents。
- 仅保存 URL、MIME、大小、建议文件名和来源元素，不读取 Cookie、Authorization、密码、表单值或响应正文。
- `.m3u8`、`.mpd`、`.key` 和非 HTTP(S) 资源明确拒绝，不提取 DRM、HLS Key 或鉴权 Token。
- 下载资源 ID 必须来自当前页本次短期缓存，仍经 Electron 原生下载和保存位置确认。

## 14. 内存修改前后对比

真实 Electron 单次探针创建 6 个 WebContents，切换省内存模式后保留 1 个、休眠 5 个；`app.getAppMetrics()` 私有内存合计从 `500700` 降到 `360604`，约 28%。Cookie 为 `1 → 1`，恢复分区仍为 `persist:qiye-sites`。该内存数值受 Chromium、GPU 和 Windows 回收时机影响，不是固定承诺；WebContents 数量、运行时清理和会话保持是确定性验收指标。

## 15. 数据迁移说明

- schema 由 v4 分阶段升级至 v8，新增弹窗策略、翻译设置、任务/提醒、用户脚本及网页内存设置。
- 各归一化与迁移可重复执行；内置脚本按稳定 ID 去重，行为型设置保持安全默认关闭。
- 不把固定站点错误迁移成会话，不修改或清除站点、空间、Chrome 书签、Google/Zoho 凭据、自动化配置、Cookie、Cache 或 `persist:qiye-sites` 登录状态。

## 16. 主要修改文件

- `electron/browser/`：原生菜单、弹窗、下载、资源识别和 WebView 生命周期。
- `electron/translation/`：Provider、选择翻译、整页提取/渲染与站点规则。
- `electron/tasks/`：本地任务、提醒调度、通知、托盘和后台行为。
- `electron/userscripts/`：metadata、匹配、审查、隔离执行、权限和存储。
- `electron/main.cjs`、`electron/preload.cjs`：主进程编排与窄 IPC。
- `renderer/`：浏览器工具栏、计划、自动化中心、设置和资源/内存界面。
- `test/unit/`、`test/integration/`：模型、安全边界和真实 Electron 回归。

## 18. 回归结果

- 工作空间、当前会话、固定站点、我的站点、Chrome 书签、内置浏览、页面动作、自动化中心和本地计划通过自动化回归。
- `persist:qiye-sites` Cookie 与浏览身份在弹窗和休眠探针中保持；没有主动清空网站登录状态。
- Google 和 Zoho 原有代码路径未移除，渲染层仍无法读取安全凭据；本轮未持有真实账号，未做云端副作用验证。
- 正式界面没有注入翻译、资源、任务、用户脚本或外部连接器假数据。

## 19. 已知限制

- 真实 SAP Support/Universal ID、Zoho Desk 和外部翻译服务仍需用户账号、密钥和线上服务状态进行端到端验证。
- 当前只实现 OpenAI-compatible 翻译 Provider；跨域 iframe 无法翻译。
- 用户脚本是受限兼容层，不是完整 Tampermonkey；同步恶意死循环无法由 JavaScript 超时可靠抢占。
- DOM 资源扫描不发现加密播放器、Service Worker 私有状态或应用内部资源，也不会尝试绕过这些边界。
- 休眠恢复 URL、身份和持久网页存储，但不恢复销毁前的内存 DOM、滚动位置、历史栈或未提交普通表单。
- 便携版尚未使用正式代码签名证书，Windows 可能显示未知发布者。
