# 栖页 0.5.0 Phase 4：用户脚本与页面动作安全运行层

## 修改文件与能力

- `electron/userscripts/metadata-parser.cjs`、`matcher.cjs`：解析 UserScript metadata，支持 `@match`、`@include`、`@exclude`、`@run-at`、受控 `@grant` 与 `@connect`，并明确拒绝 `unsafeWindow`、`@require`、`@resource` 和全局跨域通配。
- `electron/userscripts/source-service.cjs`：支持粘贴、本地 `.js` 和 HTTPS 远程来源；安装、更新前生成一次性审查令牌、SHA-256、代码摘要和行级差异，远程脚本不会静默替换本地副本。
- `electron/userscripts/engine.cjs`、`user-script-preload.cjs`：脚本在固定隔离世界运行，只能通过每次页面运行生成的临时令牌调用白名单宿主能力；页面主世界看不到宿主桥，脚本不能使用 Node、Electron、文件系统、Shell 或任意 IPC。
- `electron/userscripts/model.cjs`、`state-model.cjs`：新增脚本、批准权限、脚本专属键值和脱敏执行记录；默认只创建一个停用的内置“恢复复制与选择”脚本。
- `electron/main.cjs`、`preload.cjs`：管理端只暴露列表、审查、确认安装、启停、卸载、检查更新、当前页命令和临时内置动作；正式脚本源码不通过列表接口返回渲染层。
- `renderer/`：自动化中心统一为“签到任务 / 网页脚本 / 站点助手 / 定时任务 / 执行记录”；新增安装审查、权限确认、兼容性、Hash、更新差异、按当前网站授权和最近执行界面；页面动作面板恢复网页脚本入口。

## 安全边界

- 安装只保存本地源码副本和 SHA-256；远程更新默认关闭，检查到变化只生成审查结果，必须再次勾选确认才能替换。
- `GM_xmlhttpRequest` 由主进程代理，只允许脚本声明且用户批准的 `@connect`，默认移除 Authorization、Cookie、Origin、Referer 等凭据头并使用 `credentials: omit`。
- 脚本专属存储按脚本 ID 隔离，设置条数与总大小受限；执行日志只保存脚本、域名、状态、耗时和脱敏错误摘要。
- 登录、支付、密码、OAuth/SAML 回调和非 HTTP(S) 页面统一阻止脚本；内置恢复复制也只能临时运行，或按当前域名显式批准。
- 内置恢复复制不读取输入框、不访问网络、不绕过登录、订阅、付费墙或网站鉴权，只恢复普通正文的选择、复制、右键与 `user-select`。
- 网页主世界仍保留真实 Cookie 和密码输入值，但用户脚本隔离世界读取到空值；真实 Electron 集成测试同时验证浏览会话 Cookie 未被清除。

## 数据迁移

- schema 从 v7 升级到 v8，新增 `userScripts`、`userScriptPermissions`、`userScriptExecutions` 和 `userScriptValues`。
- 迁移可重复执行；内置脚本按稳定 ID 去重且默认停用，不会把站点、固定项或浏览会话迁移成脚本。
- 未更改 `persist:qiye-sites`，没有清理 Cookie、Cache、站点登录态、Google/Zoho 安全凭据、Chrome 书签、任务、提醒或自动化配置。

## 已知限制

- 当前兼容的是第一批轻量 GM API，不承诺与 Tampermonkey/Greasemonkey 全量兼容；不支持 `unsafeWindow`、远程依赖和资源声明。
- 3 秒超时能终止异步等待并记录超时，但浏览引擎无法可靠抢占任意恶意同步死循环；安装来源仍必须由用户审查和信任。
- 敏感页面当前采取硬阻止，没有提供放宽登录页限制的高级开关。
- 远程更新差异是安全审查用的连续变更摘要，不是完整 Git diff 查看器；原脚本不会在用户确认前被替换。
- 本阶段产物仍显示 0.4.1；完成全部 0.5.0 阶段并通过最终回归后再统一更新正式版本号。
