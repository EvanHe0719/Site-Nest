# 栖页 0.5.0 Phase 1：浏览器右键、工具栏与新窗口治理

## 修改文件与能力

- `electron/browser/`：新增地址解析、网页原生右键、外部协议、窗口策略、受控登录弹窗和下载保存服务。
- `electron/main.cjs`：将每个 `WebContentsView` 接入固定白名单菜单与受控 `window.open`；同步安全状态并提供地址栏原生菜单。
- `electron/preload.cjs`、`renderer/`：增加紧凑翻译入口、安全状态、地址栏“粘贴并转到”和弹窗策略设置。
- `test/`：增加导航、菜单、密码框、协议、策略和真实 Electron 登录弹窗回归。
- `scripts/lint.cjs`、`tsconfig.json`：建立正式 `lint` 和针对浏览器服务的 JavaScript 静态类型检查。

## 数据迁移

- schema 从 v4 升级到 v5。
- `uiSettings.sitePopupPolicies` 默认为空数组；旧数据缺失该字段时自动补齐。
- 迁移可重复执行；不会把固定站点迁移为会话，不会清理 Cookie、Cache 或 `persist:qiye-sites`。

## 验证命令与结果

- `npm.cmd run lint`：通过，64 个 JavaScript 文件；其中 43 个生产文件执行安全规则检查。
- `npm.cmd run typecheck`：通过，`electron/browser/**/*.cjs` 开启 `checkJs`。
- `npm.cmd test`：通过，单元测试 95/95，集成测试 20/20。
- `npm.cmd run build`：通过，生成 Windows x64 portable 包。
- 真实 Electron 弹窗夹具验证了普通页签、受控窗口、POST、两次 OAuth 重定向、`window.opener.postMessage`、`window.close`、共享 Cookie 和共享 Partition。
- 设置页在 1480×920 下完成截图检查，弹窗策略表单无溢出或遮挡。

## 已知限制

- “翻译选中文字”和“翻译本页”入口已归入统一菜单/工具栏，实际 Provider 与页面恢复逻辑在 Phase 2 实现；当前不会上传或记录选中文字。
- 下载采用统一保存确认与完成/失败提示，本阶段没有历史下载列表。
- SAP Support 的真实账号登录仍需用户凭据和实际服务状态；本阶段只用本地 SSO/OAuth/POST 夹具验证浏览器机制，没有宣称真实 SAP 登录成功。
- 显式站点规则可限制重定向 Origin；自动 OAuth 判断不限制重定向域，以免破坏合法多域 SSO。

## 内存变化

- 标签与 `WebContentsView` 的一一对应模型未改变，未新增后台常驻页面实例。
- 受控弹窗关闭时删除跟踪记录和窗口监听关系；主窗口关闭时统一销毁剩余受控弹窗。
- 本阶段未改变未激活标签的保活策略，也未做定量内存优化；页面休眠与释放属于 Phase 5。
