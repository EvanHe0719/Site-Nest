# 栖页 0.5.0 Phase 3：本地周月计划、提醒与托盘后台

## 修改文件与能力

- `electron/tasks/task-model.cjs`：实现 `LocalTask`、`TaskReminder` 和通知设置归一化，任务时间统一保存为 UTC，同时记录创建任务时的设备时区。
- `electron/tasks/reminder-scheduler.cjs`：使用单一计时器只等待最近一条提醒；新增、编辑、完成、删除、启动及系统恢复时统一重新调度，不为每个任务常驻一个 Timer。
- `electron/tasks/desktop-notification-service.cjs`：使用 Electron 本地通知，提供点击打开，以及系统支持动作按钮时的完成、延后 5/10/30 分钟操作。
- `electron/tasks/tray-service.cjs`、`app-background-service.cjs`：提供打开栖页、今天任务、添加任务、暂停/恢复提醒和退出菜单；只有用户启用后才关闭到托盘或随 Windows 启动。
- `electron/main.cjs`、`preload.cjs`：任务读写、状态更新、提醒延后和设置更新均通过窄 IPC；网页渲染进程不参与后台计时。
- `renderer/`：左侧新增“计划”，提供周、月、全部和完成视图；首页增加各空间“本周计划”，设置页增加“通知与后台”，任务弹窗覆盖备注、空间、状态、优先级、时间、提醒和标签。
- `test/unit/task-core.test.cjs`、`test/integration/electron-smoke.test.cjs`：覆盖模型、UTC/时区、提醒幂等、免打扰、单计时器、遗漏提醒、通知动作、托盘菜单，以及真实 Electron IPC 增删改和跨重启恢复。

## 数据迁移与安全

- schema 从 v6 升级到 v7，新增 `localTasks`、`taskReminders`、`taskSettings` 和 `timeZone`。
- 行为型设置默认值为：任务提醒关闭、关闭到托盘关闭、随系统启动关闭、启动最小化关闭；升级不会擅自改变用户原来的关闭行为。
- 任务、提醒和设置只进入既有原子 JSON 状态文件，不上传 Google，不连接外部日历，不保存网页正文或客户工单正文。
- 迁移可重复执行；提醒 ID 由任务 ID 与提前分钟数稳定生成，提醒时间不变时会保留已触发/延后/忽略状态，避免重启重复提醒。
- 未更改 `persist:qiye-sites`，没有清理 Cookie、Cache、Google/Zoho 凭据、站点、书签或浏览会话。

## 提醒与后台行为

- 调度器只持有一个最近提醒计时器；暂停提醒、勿扰时间和睡眠恢复均走同一状态机。
- 应用启动或系统从睡眠恢复后，已经错过且仍为待处理状态的提醒会立即进入触发流程；已触发的稳定提醒不会再次弹出。
- 勿扰支持跨午夜时间段；处于勿扰或用户暂停期间的提醒会延后到下一可用时间。
- 用户启用“关闭窗口后驻留托盘”后，关闭主窗口会释放网页 `WebContentsView` 并保留本地任务调度；托盘菜单“退出”才会真正结束提醒。
- “随系统启动”只在打包版本中写 Windows 登录项，开发、截图和自动化测试不会改写真实系统启动配置。

## 已知限制

- 系统通知动作按钮是否显示由 Windows 通知中心与 Electron 平台能力决定；点击通知打开任务始终注册，完整动作映射已由自动化测试验证。
- 完全退出栖页后不会继续提醒；本阶段没有注册独立 Windows 服务或计划任务。
- 没有接入 Google Calendar、Outlook 或其他外部日历，也没有上传任务数据。
- 周视图保持每列可读宽度，窄窗口需要横向滚动；打开当周时会自动把今天定位到可见区域。
