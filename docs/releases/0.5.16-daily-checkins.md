# 栖页 0.5.16：统一每日签到

日期：2026-09-05。0.5.16 是包含 NodeSeek 每日时间、自动执行开关和立即签到的新便携版；0.5.15 不包含此功能。

## 使用

完全退出旧版（包括托盘中的栖页），运行 `release/栖页-0.5.16-便携版.exe`，核对左上角为 0.5.16。在“自动化中心 → 签到任务”中找到 NodeSeek，先打开页面登录，再选择每日时间并开启自动执行。

仅在栖页运行时执行。NodeSeek 实站成功仍待用户登录验证；403、验证码和页面结构变化会停止自动操作，不记为成功。Bitwarden 兼容边界与 0.5.15 相同。

- lint、typecheck、352 项单元测试通过；动作审计 90 项，无错误或警告。

- 同次打包程序通过扩展加载、内容脚本、工具栏与弹窗回归。
- 便携 EXE 在独立临时数据目录正常启动、退出；截图确认左上角 0.5.16 与 NodeSeek 每日时间、开关及立即签到按钮。未改动用户现有使用数据。
